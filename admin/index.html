Đăng nhập bằng GitHub Token để viết bài mới

Chưa có token? Xem hướng dẫn lấy token
  1. Vào github.com/settings/personal-access-tokens/new
  2. Token name: đặt tên bất kỳ, ví dụ blog-admin
  3. Expiration: chọn No expiration (hoặc 1 năm)
  4. Repository access → Only select repositories → chọn repo web của bạn
  5. Permissions → Repository permissions → mục Contents đổi thành Read and write
  6. Bấm Generate token, copy chuỗi token rồi dán vào ô trên

Token giống chìa khóa nhà — không đưa cho ai, không chụp màn hình gửi người khác.
